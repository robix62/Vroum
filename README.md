# Vroum

Bruit de moteur thermique pour la Tesla, sans abonnement. Le régime suit la vitesse GPS, avec une boîte de vitesses simulée.

Ouvrir dans le navigateur de la voiture : https://robix62.github.io/vroum/

- **Sons réels** : Ferrari 458, BMW M1 Procar, BAC Mono et Streiter V12.
- **Mode Essai** : des pédales à l'écran pour tester sans rouler.
- **Tes propres enregistrements** : à charger par voiture, ils restent dans le navigateur.

## Crédits des sons
- [markeasting/engine-audio](https://github.com/markeasting/engine-audio), sous licence MIT : 458, Procar et BAC Mono.
- Streiter V12 du jeu Street Shift, via [ATG Vehicle Noise Synthesizer](https://github.com/ATG-Simulator/VehicleNoiseSynthesizer), sous licence MIT.
